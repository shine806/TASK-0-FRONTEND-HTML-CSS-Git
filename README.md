# FRONTEND TASK
Aetheria Teleportation Systems  Aetheria Teleportation Systems is a fictional web portal for a futuristic company that provides commercial quantum teleportation services.
The project contains three pages:

Home Page: Introduces Aetheria with a hero section, company tagline, call-to-action button, and key features of the teleportation network.
Terminal Network: Displays available teleportation terminals, departure information in a data table, a responsive image gallery, and frequently asked questions about safety and teleportation.
Booking Page: Allows users to enter passenger information, select departure and destination terminals, choose a travel class, select a date and time, and confirm their teleportation journey.

The website uses pure HTML5 and CSS3, without JavaScript, Bootstrap, Tailwind CSS, or any component libraries. Semantic HTML elements such as <nav>, <header>, <main>, <section>, <article>, <table>, <details>, and <form> are used to keep the structure simple and meaningful.
